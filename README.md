# CourseFinder-CLI

أداة سطر أوامر بسيطة في لغة بايثون للبحث عن الكورسات المجانية في منصة Great Learning واستخراج العناوين والروابط المباشرة وحفظها في ملف نصي

## مميزات الأداة

تعتمد الأداة على تقنية selenium لتصفح الموقع والتمرير الآلي لأسفل الصفحة لجلب كافة النتائج الديناميكية مع إمكانية تحديد موضوع البحث والمتصفح المطلوب عبر سطر الأوامر مباشرة دون الحاجة للإدخال اليدوي أثناء التشغيل

## المتطلبات الأساسية

تتطلب الأداة تثبيت لغة بايثون ومتصفح بريف أو إيدج إضافة إلى تثبيت المكتبات البرمجية التالية عبر الترمينال

pip install selenium beautifulsoup4

## كيفية الاستخدام

قم بتشغيل الأداة عبر سطر الأوامر مع تمرير خيار موضوع البحث كالتالي

python CourseFinder.py -t sql

يمكنك أيضا تحديد المتصفح المطلوب سواء كان بريف أو إيدج او كروم عبر خيار المتصفح

python CourseFinder.py -t python -b edge

بعد اكتمال العملية ستجد ملفا نصيا يحتوي على نتائج البحث بشكل روابط المباشرة مع اسم الدورة
